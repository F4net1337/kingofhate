## 🎵 Как подключить живой плеер ИМЕННО к Dotify (dotify.fun / @nodotify)

### Что такое Dotify и как он передаёт музыку:
[Dotify](https://dotify.fun/) (канал разработчиков [@nodotify](https://t.me/nodotify)) — это мультиплатформенный клиент, который воспроизводит музыку из различных источников (Spotify, YouTube Music, VK, Яндекс Музыка) и **имеет встроенный модуль Discord RPC**.

Когда вы слушаете плейлист в десктопном приложении Dotify, оно транслирует в Discord статус:
- **Название приложения**: `Dotify`
- **Название трека**: текущая песня
- **Автор / Плейлист**: исполнитель или название плейлиста
- **Обложка**: оригинальный арт трека
- **Таймкод**: точное время звучания

### Пошаговая инструкция для подключения Dotify к вашему сайту:

1. **Включите Discord RPC в самом Dotify**:
   - Откройте приложение Dotify на компьютере.
   - Перейдите в **Настройки ⚙️**.
   - Убедитесь, что включена опция **«Discord RPC»** (или «Интеграция с Discord / Отображать в статусе»).
2. **Подключите Lanyard (шлюз между Discord и сайтом)**:
   - Вступите 1 раз на сервер: **[discord.gg/lanyard](https://discord.gg/lanyard)** (это официальный бесплатный бот-шлюз, который считывает статус Discord без серверов).
   - Скопируйте ваш **Discord ID** (в Discord: Настройки -> Расширенные -> Включить «Режим разработчика» -> кликните правой кнопкой мыши по своему профилю в списке друзей/сервера -> «Копировать ID пользователя»).
3. **Укажите ваш Discord ID на сайте**:
   - Откройте файл `script.js` в блокноте или редакторе кода.
   - На строке 21 вставьте ваш скопированный ID:
     ```javascript
     discordId: '324892749283749283', // ваш числовой ID
     ```
4. **Готово!**
   - Теперь, когда вы включаете любой трек или плейлист в Dotify, сайт автоматически мгновенно распознаёт плеер **Dotify**, выводит обложку, автора, название и запускает эквалайзер!

## 🌐 Как бесплатно выпустить (опубликовать) сайт в интернет без поломок

Сайт полностью статический (HTML5, CSS3, ES6 JavaScript, WebGL2 шейдер). Ему не нужны базы данных, Node.js серверы или сложная компиляция. Все пути к файлам относительные (`./`), поэтому он будет работать идеально на любом бесплатном хостинге.

### Способ 1: GitHub Pages (Самый популярный и надёжный)
1. Зарегистрируйтесь или войдите на **[github.com](https://github.com/)**.
2. Нажмите зелёную кнопку **New** (создать новый репозиторий).
3. Назовите его, например, `kingofhate` (или `<ваш-ник>.github.io`), выберите тип **Public** и нажмите **Create repository**.
4. На странице репозитория нажмите ссылку **uploading an existing file** (загрузить существующие файлы).
5. Перетащите из папки `rin-green-site` файлы:
   - `index.html`
   - `style.css`
   - `script.js`
   - `gradient-waves.js`
   - `README.md`
6. Внизу нажмите зелёную кнопку **Commit changes**.
7. Перейдите во вкладку **Settings** репозитория ➔ слева выберите раздел **Pages**.
8. В пункте **Branch** выберите `main` (или `master`) и нажмите **Save**.
9. Подождите 1–2 минуты: сверху появится ссылка вида `https://<ваш-ник>.github.io/kingofhate/` — ваш сайт официально в сети!

### Способ 2: Vercel (За 1 минуту без Git)
1. Зайдите на **[vercel.com](https://vercel.com/)** и войдите через GitHub/Google.
2. В личном кабинете перетащите папку `rin-green-site` прямо в окно браузера (или подключите созданный репозиторий GitHub).
3. Нажмите **Deploy**.
4. Через 10 секунд вы получите быстрый сайт с бесплатным SSL-сертификатом по адресу `https://kingofhate.vercel.app`.

### Способ 3: Netlify Drop (Без регистрации и консоли)
1. Откройте **[app.netlify.com/drop](https://app.netlify.com/drop)**.
2. Перетащите папку `rin-green-site` в поле загрузки.
3. Сайт опубликуется моментально.
